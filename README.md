Initial Release

NORDEN II Tablet Server v1.0.0 introduces tablet access to selected NORDEN II planning and reference tools. The server runs on your Windows PC and allows a tablet connected to the same local network to open the supported modules through a web browser.

Tablet-Enabled Modules

ARM Analysis

Combat Power Board

Ballistics Computer

Current Limitations

This first release provides tablet access only to the modules listed above. Loadout Manager and Strike Planning Console are not available from a tablet in v1.0.0 and must continue to be used on the Windows PC.

Requirements

A Windows PC running the NORDEN II Tablet Server

NORDEN II installed on the host PC

A tablet with a modern web browser

The PC and tablet connected to the same local Wi-Fi or network

This is the first public tablet-server release. Additional tablet capabilities may be considered for future versions.
